The Web Platform

Demo page for UrlDocs · try selecting some text and adding a note

This small demo page stands in for any website you might want to annotate. Select any passage below — a sentence, a phrase, even a single word — and UrlDocs will show a floating Note button. Pick a color, type your note, and save. Click Share link in the top bar to copy a URL that reproduces every highlight and note, without any server storage.

How sharing works

Every annotation is stored as a set of anchors: the position of the selected text inside the page's HTML structure, plus your note text and chosen color. All of that is compressed and placed in the URL fragment (the part after #).

A URL fragment is never sent to the server, which means UrlDocs can ship as a purely static website — no database, no accounts, no backend.

When someone opens your shared link, the app loads the original page and re-applies your annotations on top of it.

How anchors stay stable

An anchor points to a specific text node in the page: which element it lives in (a path from the page root) and where inside that element's text it begins and ends. Because the anchor describes where the text is rather than copying the text itself, a highlight keeps working even when the page re-renders around it.

  • Yellow — the default highlight color.
  • Green — for confirmations and things that work.
  • Blue — for questions and things to double-check.

Limitations

Remote pages are fetched through public CORS proxies, so some sites (ones that block proxy traffic, or that rely heavily on JavaScript) may not load, or may load without their scripts. If the underlying page's HTML changes after you share a link, individual highlights may drop — UrlDocs keeps the ones that still fit.
